About Us · เกี่ยวกับเรา

เราคือใคร และเราขายอะไร

Kitti Tokens เป็นธุรกิจเล็กที่ช่วยให้เข้าถึง AI API จากหลายผู้ให้บริการได้ง่ายขึ้น — พร้อมตัวเลือกแชทบอทส่วนตัว

แนะนำธุรกิจ

ตลาด API AI ที่เรียกง่าย สำหรับคนเริ่มจริง

Kitti Tokens ก่อตั้งโดย กิตติภูมิ ประสมทรัพย์ (Kittipoom) นักศึกษา ปวส. เทคโนโลยีธุรกิจดิจิทัล — เป็น MSME / สตาร์ทอัพนักศึกษาที่อยากทำให้การใช้ AI API ไม่ซับซ้อนเกินไป

เราขายอะไร: เครดิตโทเคนและ API key สำหรับเข้าถึงโมเดลจากหลายผู้ให้บริการ (AI API marketplace) รวมถึงบริการตั้งแชทบอทส่วนตัว (private chatbot) ตามความต้องการ

ทำมานานแค่ไหน: ยังเป็นธุรกิจเริ่มต้น / โปรเจกต์นักศึกษา — ขอบเขตและพาร์ตเนอร์ผู้ให้บริการยังขยายต่อเนื่อง รายละเอียดอาจปรับตามพาร์ตเนอร์

ทำไมถึงเริ่ม: เห็นว่าการสมัครทีละค่ายจัดบิลยาก และทดลองโมเดลหลายตัวเป็นเรื่องยุ่งสำหรับมือใหม่ จึงอยากรวมทางเข้าให้สั้นลง จ่ายตามที่ใช้

จุดต่าง: แพ็กเกจชัด ราคาตัวอย่างเป็นมิตร เอกสารภาษาไทยอ่านง่าย และมีทางเลือกแชทบอทส่วนตัวไม่บังคับซื้อคู่กับ API
